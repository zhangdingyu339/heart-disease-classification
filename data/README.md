# Data access

Download `heart.csv` from version 1 of:
https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction

Alternatively, run `python download_data.py` from the repository root. The
automatic download uses Kaggle's public dataset endpoint and may require manual
download if access rules change. The dataset contains 918 rows, 11 predictors,
and the binary `HeartDisease` target. Raw data are excluded from the public package.
Refer to the original dataset page for source attribution and reuse terms.
